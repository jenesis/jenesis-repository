Publishing here goes through the same ingress edge a build tool's upload takes: the artifact is screened by the compliance gate before any format lays it out, so a held artifact lands in quarantine and a refused one is not published at all. A build tool is how artifacts normally arrive - this screen is for the occasional artifact that has no build behind it.

A hosted repository in tenant. A proxy or a group view is served from its backings and takes no direct write. Where the artifact lands, as its format lays it out - the same path a client would publish to, without the repository prefix. The format that claims the path is the one that stores it; a path no installed format claims publishes nothing.
