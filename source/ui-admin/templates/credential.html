Project grants

Key expiry

An ISO-8601 duration from now (e.g. P30D) or an absolute instant; blank clears it.

Rotate

Mints a successor key with the same grants and allowlist, and sets this key to expire after an overlap so callers can migrate without downtime. The new key is shown once.

Source-IP allowlist

Comma-separated CIDRs or addresses (e.g. 203.0.113.0/24, 10.1.2.3); blank allows any address. A request from an address outside the list is refused even with a valid key. The server reads the source address from the connection, honouring forwarded headers only behind a trusted proxy.

Delete

Removes the credential; its key stops working immediately.
