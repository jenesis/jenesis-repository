Deployment-wide runtime configuration, shared by every repository node. The same values the /api/settings endpoint and the CLI edit, so the three administration surfaces stay equal. Each knob shows its documentation, its effective value against the default, and whether a change applies live (a node's next scheduled re-read) or only on restart. A blank value reverts to the default.

Repository definitions

Named repositories routed at runtime: hosted, proxy <url> [nocache] or group a,b push=x. They add to or override the deployment's file-configured repositories and route on the next request.

Format upstreams

The proxy upstream each format pulls its local misses through, over the format's own default and the deployment default.

Upstream credentials

Credentials the pull-through proxies send to a private upstream (an internal registry or an authenticated mirror), keyed by host. The secret is write-only - only the hosts are listed, never the credential.

Backup & restore

Download every stored setting as one JSON bundle, or restore one - the same bundle the /api/settings/export endpoint and the CLI produce. The bundle is credential-free by construction - every secret-kind setting is excluded, so a stored secret never travels in the backup. An import is validated first and refused whole if any value would not resolve, then it replaces the current stored settings.
