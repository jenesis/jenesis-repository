Credential-lifetime policy

New keys default to 90 days; the maximum lifetime is unlimited. A maximum caps every new key and pulls any longer or non-expiring key back to the limit.

Leak detection

Jenesis keys carry a jenk_ prefix and a checksum, so a secret scanner can spot a leaked key in public code. Point your scanning partner's webhook at POST /api/leaked on the repository server and a reported key is revoked automatically, before it can be abused. Set jenreg.leaked-secret on the server to require signed reports (a hex HMAC-SHA256 of the body in the Jenesis-Leaked-Signature header).

Roles

A role names a bundle of rights so a grant reads "deploy" instead of raw tokens. The built-in read-only, deploy and admin roles form a hierarchy; add your own from the cache tokens (cache:read, ), or *.

Keyless CI (OIDC trust)

A CI job exchanges the OIDC id-token its platform issues for a short-lived key at POST /api/token - no static secret to store. Each trust admits one issuer; a token whose audience and subject (glob) match is minted a key with the trust's grant for its lifetime.
