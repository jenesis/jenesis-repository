What governs every credential of this [[${scopeWord}]] rather than one: how long a new key lives, how a leaked one is revoked, and the roles a grant is written in.

Credential-lifetime policy

New keys default to 90 days; the maximum lifetime is unlimited. A maximum caps every new key and pulls any longer or non-expiring key back to the limit.

Leak detection

Jenesis keys carry a jenk_ prefix and a checksum, so a secret scanner can spot a leaked key in public code. Point your scanning partner's webhook at POST /api/leaked on the repository server and a reported key is revoked automatically, before it can be abused. A report is acted on only when it is signed with the secret jenrepo.leaked-secret names (a hex HMAC-SHA256 of the body in the Jenesis-Leaked-Signature header).

Roles

A role names a bundle of rights so a grant reads "deploy" instead of raw tokens. The built-in read-only, deploy and admin roles form a hierarchy; add your own from the cache tokens (cache:read, ), or *.
