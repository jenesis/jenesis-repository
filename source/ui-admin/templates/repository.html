Route this repository

Hardened proxy screening hardened

This repository is a hardening proxy: every untrusted upstream body is spooled and fully screened before a byte is released. A body that could not be screened (oversize, stalled, drifted, unparseable, or one an inspector failed on) is refused, and appears on the Refused page.

Published index

An incremental, content-addressed index an external consumer syncs against - fetch the descriptor, diff, fetch only the unseen chunks. Read-only; the index pass publishes it on its schedule.

Retire and delete

Absent formats

This repository records data for ecosystem(s) no installed format can place. Their artifacts are unreachable but kept - nothing is deleted on absence - and garbage collection refuses this repository until each is resolved: reinstall (or re-enable) the format, or retire its records here. Retiring lets the collector reclaim the ecosystem's content on its next pass; purge the format module's remaining pointers on the Modules screen.
