Policy

A version is kept only if it satisfies every rule; a pinned version is always kept, whatever the rules say. Each rule is a repository setting: this repository's own value, else its tenant's, else the deployment's. Durations are written P90D or 90d, and none switches a rule off for this repository where a wider level sets one.

In force: keep-last 0, max-age none, prerelease-expiry none, not-downloaded-for none.
