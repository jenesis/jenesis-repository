Where the deployment fetches what it does not hold. Nothing is proxied from anywhere until an upstream is named here, so this is a step every proxying deployment takes.

Format upstreams

The proxy upstream each format pulls its local misses through. A format fetches nothing from anywhere until one is named here.

Upstream credentials

Credentials the pull-through proxies send to a private upstream (an internal registry or an authenticated mirror), keyed by host. The secret is write-only - only the hosts are listed, never the credential.

Repository routing

How a repository answers a local miss, written in clauses: writable accepts uploads, and each fallback <url> [nocache] [harden] [unscreened] or fallback <repository> is consulted in order. A definition is the deployment's and is keyed by name, so it routes the repository of that name in every tenant; it adds to or overrides the file-configured repositories and routes on the next request.

For tenant acme

What this tenant uses instead of the deployment's above. The outbound screen is the deployment's either way.

Format upstreams

None: this tenant pulls through the deployment's upstreams.

Repositories routed on their own

A repository that sets its own routing routes by it over the deployment's definitions here; it is set on the repository's own page, and its routing badge shows it in the repositories list.
