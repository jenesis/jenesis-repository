Credentials, settings, ceilings and the tenant list are read through a time-bounded cache on each node, so a request pays for nothing twice; a write on this node is seen here at once, and another node's within the ttl. This node is node; every other node keeps its own caches until their ttl.

Held writes

Download counts, credential use and some counters are held in memory and written on a cadence, so a busy repository pays one write per interval rather than one per request. What a node holds is written when it stops, and can be written now to read a figure before its cadence comes round.
