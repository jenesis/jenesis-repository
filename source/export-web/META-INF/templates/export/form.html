Publish every version a repository holds to another repository - another deployment of this product, or any repository manager - through the protocol the format's own client publishes with, so the other side needs no importer. A version already there is not sent again, so an export can be run again or resumed, and a held version is never sent. The job runs in the background; this screen shows where it has got to.
