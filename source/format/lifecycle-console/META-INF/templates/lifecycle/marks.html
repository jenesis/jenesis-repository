A deprecated version still installs, and its client warns whoever installs it; a yanked one stays for whoever already pinned it, and no new resolution picks it. Each client sees the mark in its own metadata - npm's deprecation message, Cargo's and RubyGems' yank, NuGet's unlisting - and its own command sets the same mark this page does.

This repository shows a lifecycle mark to no client.
